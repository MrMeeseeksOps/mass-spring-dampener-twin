# Learning journal

For each experiment record:

1. Hypothesis and derivation, with SI units.
2. Commit or source snapshot, Python version, parameters, timestep and seed.
3. Command and output artifact paths.
4. Observed errors, convergence slopes and energy behavior.
5. Whether evidence supports the hypothesis; numerical versus modeling errors.
6. One unanswered question and the next controlled experiment.

Start with: why does a displacement-only observation fail to identify instantaneous velocity exactly? How would you test whether velocity noise or stiffness mismatch dominates forecast RMSE?
